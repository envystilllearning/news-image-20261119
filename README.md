# news-image-20261119 — Thursday 19 November 2026 in one image

A light one-page newspaper poster (1024×1024 PNG) summing up Thursday
19 November 2026 in **39 verified stories**: 3 large illustrated features,
10 small illustrated cards with mini data-viz, a world map with numbered
pins, 27 numbered briefs, a region strip, a BY FIELD strip, a THE DAY IN
NUMBERS strip, a DATE CHECK box and a sources footer.

## Files

- `generate.py` — draws `entry.png` with Pillow (run locally:
  `python3 generate.py`). Deterministic: two runs produce identical bytes.
- `entry.png` — the poster (1024×1024, ~191 KB, under the 1 MiB cap).
- `main.ts` — the submitted program (Node 22, stdlib only): copies
  `entry.png` to `/output/entry.png`.
- `LICENSE` — MIT (with an `SPDX-License-Identifier: MIT` line).
- `BUILD-REPORT.md` — claim list with one source per story, leaderboard
  pattern applied, validation results. Coordination file, not part of the
  entry.
